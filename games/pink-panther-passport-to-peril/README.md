## Bring your own game files

Place your legally obtained game files in one of these locations:

```text
~/retro-game-files/pink-panther-passport-to-peril/

local/sources/pink-panther-passport-to-peril/
```

See `recipe.yml` for expected metadata. Checksums still need to be filled in before publishing.

RETRO_GAME_SOURCE_DIR=~/retro-game-files RETRO_GAME_RUNTIME_DIR=~/retro-game-runtime ./games/pink-panther-passport-to-peril/launch.sh
